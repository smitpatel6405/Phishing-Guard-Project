# Extension Icons

This directory should contain the following icon files for the PhishGuard Chrome extension:

- `icon16.png` - 16x16 pixels (toolbar icon)
- `icon48.png` - 48x48 pixels (extension management page)
- `icon128.png` - 128x128 pixels (Chrome Web Store)

## Icon Requirements

- **Format**: PNG with transparency support
- **Style**: Should represent security/protection (e.g., shield, lock, guard)
- **Colors**: Use the extension's color scheme (blue/purple gradients)

## Creating Icons

You can create these icons using:
- Online icon generators (e.g., favicon.io, realfavicongenerator.net)
- Image editing software (GIMP, Photoshop, Figma)
- AI image generation tools

## Temporary Solution

Until you create custom icons, you can:
1. Use any 16x16, 48x48, and 128x128 PNG images
2. Rename them to match the required filenames
3. The extension will work with placeholder icons

## Note

The extension will not load without these icon files. Make sure to add them before testing the extension.
